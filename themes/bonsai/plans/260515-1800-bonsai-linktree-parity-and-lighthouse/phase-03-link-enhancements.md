# Phase 3: Per-link enhancements + page-level share/QR/vCard

## Overview

Close the largest Linktree-parity gap in one phase by adding the medium-effort, high-value features all Linktree users rely on:

**Per-link (5 new optional fields):**
- `image` — thumbnail next to icon
- `featured` — boolean, applies `.link--featured` styling (size↑, accent border)
- `startDate` / `endDate` — build-time visibility window (Hugo's `now` vs param)
- `rel` — augment auto-injected `noopener noreferrer` (e.g. add `sponsored`, `nofollow`)
- `note` — small caption under title (sub-line, muted)

**Page-level (3 new opt-in features):**
- `params.share` — render a share button row (`navigator.share` + clipboard-copy fallback)
- `params.qr` — render QR code of canonical page URL via Hugo `images.QR` (Hugo ≥0.140 built-in)
- `params.vcard` — generate `/vcard.vcf` static file at build time + a download link

## Requirements

### Functional

**Per-link fields (all optional, additive):**

| Field | Type | Default | Effect |
|-------|------|---------|--------|
| `image` | string (URL) | — | Render thumbnail `<img>` at `link__thumb` slot (24–32 px square). Falls back to `icon` if both set (image wins). |
| `featured` | bool | false | Add `.link--featured` class — slightly larger padding, accent-tinted border, optional star/sparkle micro-icon. |
| `startDate` | string (RFC3339 date) | — | Link rendered only if `now >= startDate`. |
| `endDate` | string (RFC3339 date) | — | Link rendered only if `now <= endDate`. |
| `rel` | string | — | Appended to auto `noopener noreferrer` (space-joined). Use for `sponsored`, `nofollow`, `me`. |
| `note` | string | — | Small caption below title (e.g. "Sponsored", "Limited time"). |

**Page-level opt-ins:**

| Param | Type | Default | Effect |
|-------|------|---------|--------|
| `params.share` | bool | false | Render `<button class="bio__share">` after links. Uses `navigator.share()` when supported; falls back to clipboard copy + ARIA-live toast. |
| `params.qr` | bool | false | Render QR code as `<img>` (PNG generated by Hugo) in a `<details>` collapsible at page bottom. Encodes `Permalink`. |
| `params.vcard` | bool | false | Hugo task at build time writes `static/vcard.vcf` derived from `params.name`, `params.email`, `params.location`, `params.jobTitle`, social links. Renders a "Save contact" link/button. |

### Non-functional

- Build-time visibility (`startDate`/`endDate`) — Bonsai is static; visibility re-evaluated only at next build. Document this clearly. If user needs runtime visibility (e.g. weekly recurring), they should use a GitHub Actions cron rebuild.
- Share button JS: vanilla, <2 KB raw, loaded `defer`, only when `params.share = true`. Total page JS budget incl. theme-toggle: ≤ 3 KB raw.
- QR generation: Hugo `images.QR` requires Hugo ≥ 0.140 — bump theme minimum in `theme.toml` if not already.
- vCard generation: Hugo template emits `.vcf` via `outputFormats`; no external script.
- All new features off by default. v0.4 sites unaffected.

## Implementation Steps

1. **Link visibility window** — top of `link-button.html`:
   ```go
   {{- $now := now -}}
   {{- $startOk := true -}}
   {{- $endOk := true -}}
   {{- with .startDate }}{{ $startOk = ge $now (time .) }}{{ end -}}
   {{- with .endDate }}{{ $endOk = le $now (time .) }}{{ end -}}
   {{- if and $startOk $endOk -}}
     …render link…
   {{- end -}}
   ```

2. **Image vs icon branching** — inside the `<a>`:
   ```html
   {{- with .image -}}
     <img class="link__thumb" src="{{ . | strings.TrimPrefix "/" | relURL }}" alt="" width="24" height="24" loading="lazy" decoding="async" />
   {{- else with .icon -}}
     <span class="link__icon" aria-hidden="true">{{ partial "icon.html" . }}</span>
   {{- end -}}
   ```

3. **`featured` class + `rel` merge**:
   ```html
   {{- $classes := "link" -}}
   {{- if .featured }}{{ $classes = printf "%s link--featured" $classes }}{{ end -}}
   {{- $rel := "noopener noreferrer" -}}
   {{- with .rel }}{{ $rel = printf "%s %s" $rel . }}{{ end -}}
   <a class="{{ $classes }}" href="{{ .url }}"
      {{ if $external }}target="_blank" rel="{{ $rel }}"{{ end }}>
   ```

4. **Note caption** — inside `.link__title` block:
   ```html
   <span class="link__title">
     {{ .title }}
     {{- with .note }}<span class="link__note">{{ . }}</span>{{- end -}}
   </span>
   ```

5. **Share button**:
   - Create `partials/share-button.html`.
   - Create `static/js/share.js`:
     ```js
     (function(){
       var btn = document.querySelector('[data-share-url]');
       if(!btn) return;
       var toast = document.querySelector('.bio__share-toast');
       function showToast(msg){
         if(!toast) return;
         toast.textContent = msg;
         toast.hidden = false;
         setTimeout(function(){ toast.hidden = true; }, 2000);
       }
       btn.addEventListener('click', async function(){
         var url = btn.getAttribute('data-share-url');
         var title = btn.getAttribute('data-share-title');
         try{
           if (navigator.share){ await navigator.share({title:title, url:url}); return; }
           if (navigator.clipboard){ await navigator.clipboard.writeText(url); showToast(btn.getAttribute('data-toast-copied')||'Copied'); return; }
           prompt('Copy link:', url);
         } catch(e){ showToast(btn.getAttribute('data-toast-failed')||'Could not share'); }
       });
     })();
     ```
   - Load `defer` from `head.html` only when `params.share = true` — pattern mirrors theme-toggle.

6. **QR block** — `partials/qr-block.html`:
   ```go
   {{- if site.Params.qr -}}
   {{- $url := .Permalink -}}
   {{- $qr := images.QR $url -}}
   <details class="bio__qr">
     <summary>{{ i18n "show_qr" | default "Show QR code" }}</summary>
     <img class="bio__qr-img" src="{{ $qr.RelPermalink }}" width="200" height="200"
          alt="{{ i18n "qr_alt" | default "QR code to this page" }}" loading="lazy" decoding="async" />
   </details>
   {{- end -}}
   ```
   Note: `images.QR` returns a resource; Hugo emits a PNG at build time.

7. **vCard output** — add to `hugo.toml` (theme-managed via `exampleSite` and documented in README):
   ```toml
   [outputs]
     home = ["HTML", "RSS", "VCard"]
   [outputFormats.VCard]
     mediaType = "text/vcard"
     baseName = "vcard"
     isPlainText = true
     notAlternative = true
   ```
   Then `layouts/_default/vcard.vcf`:
   ```
   BEGIN:VCARD
   VERSION:3.0
   FN:{{ site.Params.name | default site.Title }}
   {{ with site.Params.jobTitle }}TITLE:{{ . }}{{ end }}
   {{ with site.Params.email }}EMAIL:{{ . }}{{ end }}
   {{ with site.Params.location }}ADR:;;{{ . }};;;;{{ end }}
   URL:{{ site.BaseURL }}
   {{ range site.Params.links }}{{ if not (or (strings.HasPrefix .url "mailto:") (strings.HasPrefix .url "tel:")) }}URL;TYPE={{ .title | upper }}:{{ .url }}
   {{ end }}{{ end }}
   END:VCARD
   ```
   Link from `bio-card.html` when `params.vcard = true`:
   ```html
   <a class="bio__vcard" href="{{ `vcard.vcf` | relURL }}" download>{{ i18n "save_contact" | default "Save contact" }}</a>
   ```

8. **i18n keys** — append to en/vi toml.

9. **CSS** — append rules listed in Architecture. Verify gzipped delta ≤ 200 B.

10. **README documentation** — new "Per-link fields" subsection (table); new "Page actions: share / QR / vCard" subsection with opt-in examples.

11. **exampleSite demo** — enable `share = true` and `qr = true` (lightweight; both Hugo-native). vCard left off by default to keep demo focused.

12. **Build verification** — `hugo --gc --minify`. Check `public/vcard.vcf`, `public/index.html` has share button if enabled, QR PNG generated under `public/`.

## Risk Assessment

| Risk | Mitigation |
|------|------------|
| `images.QR` unavailable on Hugo < 0.140 | Bump `theme.toml` min_version. CI installs ≥ 0.140 already (latest). |
| Share clipboard API in non-secure contexts (http://) fails | Toast falls back to `prompt(url)` for legacy/insecure environments. Documented limitation. |
| vCard contains email leaked in plaintext from `params.email` | Document: vCard exposes whatever user puts in params. Off by default. |
| Scheduled visibility re-evaluated only at build | Documented; cron-rebuild recipe in README. |
| Featured link standing out too much breaks zen aesthetic | Subtle accent border, only 1.5× padding. Designer review at PR time. |
| Per-link `image` adds extra HTTP requests | Each `<img>` is `loading="lazy"`, `decoding="async"`. Not on critical path. |
| QR generated per build inflates `public/` size | One PNG per page; ~3-5 KB each. Negligible. |

## Security Considerations

- `rel` merging: user input appended to `noopener noreferrer` baseline — no way to *remove* the safe defaults, only add.
- Share JS runs only on click — no auto-execution, no exfiltration risk.
- vCard contains only data the user explicitly set in params; no surprise email/phone leakage.
- QR encodes only the page's own `Permalink` — no third-party data flow.
